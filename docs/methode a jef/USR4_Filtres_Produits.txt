Mission USR4 - Filtrage des produits (Version finale validée)

1. Objectif :
Permettre à l'utilisateur de filtrer la liste complète des produits par catégorie, marque et prix (min/max).

2. Méthode :
- Utilisation d'un formulaire HTML standard placé dans le menu latéral (v_categories.php).
- L'attribut action du formulaire pointe vers index.php?uc=voirProduits&action=nosProduits.
- Traitement des données via POST dans le contrôleur (ControleurVoirProduits.php).
- Requête SQL dynamique sécurisée avec PDO (requêtes préparées) pour éviter les injections SQL.
- Persistance de l'état des filtres : les listes déroulantes conservent la valeur sélectionnée après soumission grâce à l'attribut 'selected'.

3. Sécurité et Validation (BTS SIO) :
- Utilisation systématique d'un tableau de paramètres avec execute() pour protéger contre les injections SQL.
- Validation côté serveur (Contrôleur) : Vérification des nombres négatifs. Si un prix est inférieur à 0, un message d'erreur est affiché et le filtre est annulé.
- Nettoyage des entrées : Gestion des chaînes vides envoyées par le formulaire pour éviter les erreurs SQL.
- Comparaison stricte avec null ($prixMin !== null) pour ne pas exclure les produits à prix 0.

4. Expérience Utilisateur :
- Ajout de "placeholders" (exemples) dans les champs de prix pour guider l'utilisateur.
- Bouton "Réinitialiser" pour remettre tous les filtres à zéro.
- Gestion des résultats vides : Si aucun produit ne correspond aux filtres, un message explicatif s'affiche ("Désolé, aucun produit ne correspond à votre recherche.").

5. Logique SQL :
SELECT ... FROM produit WHERE 1=1 
AND idCateg = :idCateg 
AND idMarque = :idMarque 
AND prix >= :prixMin 
AND prix <= :prixMax
ORDER BY prix ASC;
(Le WHERE 1=1 permet d'ajouter dynamiquement des "AND" sans se soucier si c'est la première condition ou non).

6. Fichiers concernés :
- Contrôleur : controleurs/ControleurVoirProduits.php (méthode voirTousProduits)
- Modèle : modele/ModeleFront.php (méthode getProduitsFiltres)
- Vue : vues/v_categories.php (formulaire de filtrage)
- Vue : vues/v_produits.php (affichage des résultats)
