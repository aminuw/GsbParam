Mission USR10 - Gestion des Commandes (Conforme au Cahier des Charges)

1. Objectif :
Offrir à l'administrateur une interface complète pour suivre les ventes, consulter le détail des paniers clients et mettre à jour l'état d'avancement des commandes.

2. Structure SQL des jointures :
- Pour la liste globale des commandes :
  SELECT c.idCommande, c.dateCommande, cl.nom, cl.prenom, e.libelle AS etat, e.idEtat
  FROM commande c
  INNER JOIN client cl ON c.idClient = cl.idClient
  INNER JOIN etat_commande e ON c.idEtat = e.idEtat
  ORDER BY CAST(c.idCommande AS UNSIGNED) DESC;

- Pour le détail d'une commande (Articles) :
  SELECT p.nom, p.prix, m.libelleMarque, cat.libelle AS libelleCateg, co.qte
  FROM contenir co
  INNER JOIN produit p ON co.idproduit = p.idproduit
  INNER JOIN marque m ON p.idMarque = m.idMarque
  INNER JOIN categorie cat ON p.idCateg = cat.idCateg
  WHERE co.idCommande = :idCommande;

3. Fonctionnalités implémentées :
- Affichage d'un tableau récapitulatif de toutes les commandes (ID, Date, Client, État actuel).
- Calcul dynamique du montant total de la commande (Prix * Quantité) dans la vue détaillée.
- Formulaire de mise à jour de l'état via une liste déroulante avec le bouton "Valider". L'état actuel est pré-sélectionné grâce à l'attribut 'selected'.
- Bouton "Liste des articles" pour consulter le détail de chaque commande (s'ouvre dans la même page).
- Message d'alerte si aucune commande n'est présente.

4. Sécurité et Robustesse (BTS SIO) :
- Accès strictement réservé au rôle Administrateur (vérifié par requireAdmin() dans le Routeur).
- Requêtes préparées pour toutes les opérations SQL.
- Gestion des erreurs via try/catch lors de la mise à jour de l'état d'une commande, avec affichage d'un message d'erreur explicite au lieu d'un crash.
- Respect de l'intégrité référentielle (on ne peut pas supprimer un produit lié à une commande).

5. Fichiers concernés :
- Contrôleur : controleurs/ControleurAdmin.php (gestionCommandes, voirArticles, modifierEtat)
- Modèle : modele/ModeleFront.php (getToutesLesCommandes, getArticlesCommande, getTousLesEtats, modifierEtatCommande)
- Vues : vues/v_listeCommandes.php, vues/v_detailCommande.php
