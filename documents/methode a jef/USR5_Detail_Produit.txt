Mission USR5 - Consulter le détail d'un Produit

1. Objectif :
Afficher une fiche détaillée pour chaque produit comprenant toutes les informations techniques (marque, contenance, stock) et les avis clients.

2. Structure de la requête SQL (Jointures) :
Pour obtenir les libellés au lieu des identifiants (idMarque, idUnite), nous devons lier les tables :
SELECT p.*, m.libelleMarque, u.libelleUnite
FROM produit p
INNER JOIN marque m ON p.idMarque = m.idMarque
INNER JOIN unite u ON p.idUnite = u.idUnite
WHERE p.idproduit = :id;

3. Informations à afficher :
- Nom et Photo
- Note moyenne (calculée à partir de la table avis)
- Description complète
- Marque (ex: 'Laino', 'Weleda')
- Contenance (ex: '200 ml')
- Stock disponible (quantiteStock)
- Produits associés (table associer)

4. Sécurité (BTS SIO) :
- Utilisation de htmlspecialchars() pour l'affichage des données.
- Requête préparée pour récupérer le produit par son ID.

5. Démarche :
- Mise à jour de la méthode getUnProduit() dans le Modèle pour inclure les jointures.
- Amélioration de la vue v_avis.php pour en faire une véritable "Fiche Produit" complète.
